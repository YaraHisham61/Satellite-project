# Satellite Imaging Project: Cloud Detection with Deep Learning

A deep learning-based system for detecting clouds in satellite imagery using PyTorch.

## Key Features
- **Model Architectures**: Includes `CloudNet`, `CloudNetDeepSupervision`, and attention-based variants.
- **Efficient Inference**: Optimized for GPU/CPU deployment.
- **Data Preprocessing**: Tools for RLE encoding/decoding and patch extraction.
- **Modular Design**: Easy integration with custom datasets.
